# ISEvents
**ISEvents** is a regional marketplace platform for event equipment and services. Its goal is to simplify the process of planning events by connecting private customers and businesses with local providers through one centralized platform.

Instead of contacting multiple providers individually, customers can create a single request for the equipment and services they need. ISEvents distributes this request to suitable regional providers, allowing them to respond with availability and offers.

The platform is initially focused on providers in the **Isenbüttel and Gifhorn region in Germany**, while its architecture is designed to support future expansion into additional regions.

ISEvents is built as a modern cloud-based web application using **TypeScript, React, Vite, Microsoft Azure, and Supabase**. Microsoft Azure provides the hosting, API, business logic, and communication infrastructure, while Supabase is used as the central PostgreSQL database and can also provide services such as authentication, storage, real-time functionality, and Row Level Security.

The long-term vision of ISEvents is to create an easy-to-use digital ecosystem for event planning, where customers can discover and request equipment and services, providers can manage incoming requests and bookings, and intelligent features such as conversational AI can further simplify the booking process.
